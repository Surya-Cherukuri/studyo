How it's made

Every frame is drawn, not filmed.

Our own animation engine draws each lesson from a script, so the picture always matches what the narrator says.

Step 1

One idea, one line at a time

The script is written like a teacher talking to one student: a question, the idea built in small moves, one worked example, a recap. It's written with AI help and checked by a person.

Step 2

Pictures that compute

The figures run the actual algorithm or the actual physics. The breadth-first search numbers come from a real search, and the doughnut's 395 cm³ is worked out, not typed in.

Step 3

Voice, sound, then a check

A narrator voice, music and sound effects go on, then an automatic check looks for words that overlap or run off the screen before a lesson is published.
